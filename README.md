# Обретая лица. Играя со временем

Лэндинг фестиваля независимого кино "Обретая лица. Играя со временем".

Сайт представляет концепцию фестиваля, открытый набор 2026 года, программу фильмов 2025 года, команду и ссылки на социальные сети фестиваля. Визуальное направление строится вокруг статичной макеты в редакционном стиле с кастомной типографикой, локальными медиа-ресурсами и лёгкими JavaScript-взаимодействиями.

## О фестивале

"Обретая лица. Играя со временем" — это фестиваль независимого любительского кино в Тюмени. Его центральная тема — исследование идентичности через время. Проект стремится создать пространство для междисциплинарного диалога, визуальных экспериментов и роста регионального кинематографического сообщества.

## Структура проекта

- `index.html` содержит разметку страницы и текст фестиваля.
- `style.css` определяет визуальную систему, макет, типографику и адаптивное поведение.
- `index.js` рендерит программу фильмов и управляет интерактивным поведением интерфейса.
- `images/` хранит фоны, постеры фильмов, карточки команды и favicon.
- `fonts/` хранит локальные файлы шрифтов, используемые сайтом.

## Фичи

- Вводный раздел с навигацией и ссылками на социальные сети
- Описание фестиваля и его позиционирование
- Раздел с открытым набором на 2026 год
- Динамически отображаемая программа фильмов 2025 года из массива данных JavaScript
- Адаптивный слайдер команды на маленьких экранах
- Взаимодействие "Показать больше" для списка фильмов на меньших разрешениях
- Полностью статическое развертывание без этапа сборки

## Технологический стек

- HTML5
- CSS3
- Vanilla JavaScript
- Локальные ресурсы (.webp, .ttf, .ico)

## Управление контентом

- Тексты фестиваля написаны непосредственно в index.html.
- Программа фильмов хранится в массиве filmsData в index.js.
- Карточки команды, фоны и постеры управляются через каталог images/.
- Ссылки на подачу заявок в данный момент размещены в кнопках "Подать заявку" в index.html 
и могут быть обновлены там.

## Деплой

Проект подходит для развертывания на любой платформе для статического хостинга, включая GitHub Pages, Netlify, Vercel статический хостинг или собственный веб-сервер.
